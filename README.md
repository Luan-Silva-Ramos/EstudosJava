# EstudosJava ☕

Repositório dedicado aos meus estudos e exercícios em **Java**, desenvolvido para praticar conceitos de programação e registrar minha evolução durante o aprendizado.

## 📚 Organização do projeto

```text
EstudosJava/
└── src/
    ├── Exemplos/
    ├── Praticando/
    ├── Questoes/
    └── ListadeExercicios01.java
```

### Pastas e arquivos

- **`Exemplos/`** — exemplos de código e testes de conceitos.
- **`Praticando/`** — exercícios práticos organizados por questão.
- **`Questoes/`** — soluções de exercícios identificados por número.
- **`ListadeExercicios01.java`** — arquivo com uma lista de exercícios.

## 🛠️ Tecnologias e ferramentas

- Java
- IntelliJ IDEA

## 🎯 Objetivos

- Praticar lógica de programação.
- Desenvolver habilidades na linguagem Java.
- Resolver exercícios e consolidar conhecimentos.
- Manter um registro da minha evolução como desenvolvedor.

## ▶️ Como executar

1. Clone este repositório.
2. Abra o projeto em uma IDE compatível com Java, como o IntelliJ IDEA.
3. Escolha o arquivo que deseja executar.
4. Execute a classe que contém o método `main`.

> Alguns arquivos podem ser exercícios independentes. Execute cada classe conforme sua estrutura e seus requisitos.
